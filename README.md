# 教父文献资料库（Church Fathers Library）

本目录收录早期基督教教父著作的公版（Public Domain）资料，按时代与学派分类保存。
下载日期：2025-09-09

## 分类总览

```
church_fathers/
├── apostolic_fathers/         使徒教父（约90–150年）— 希腊文+英译
├── apologists/                护教士（2世纪）— 游斯丁、他提安、雅典那哥拉、狄奥菲鲁斯、亚里斯泰迪斯
├── irenaeus/                  爱任纽（约130–202）—《驳异端》
├── latin_western_early/       拉丁西方早期教父（2–3世纪）— 特土良、希坡律陀、居普良、诺瓦替安
├── alexandrian_school/        亚历山大学派（2–3世纪）— 克莱门特、俄利根
├── church_history_others/     教会史与其他（3–4世纪）— 优西比乌、拉克坦丢、安波罗修等
├── eastern_post_nicene/       东方后尼西亚教父（4–8世纪）— 亚他那修、加帕多家三教父、金口约翰、以法莲等
├── latin_western_late/        拉丁西方后尼西亚教父（4–5世纪）— 希拉流、耶柔米、奥古斯丁、里奥一世等
└── collections/               全部原档（38卷全集 PDF 存档，分类目录均为其硬链接）
```

## 来源说明

- **分类目录**（apostolic_fathers 除外）中的 PDF 为 `collections/` 下原档的**硬链接**，不重复占用磁盘空间。
- **ANF**（Ante-Nicene Fathers，前尼西亚教父，10卷）与 **NPNF** 第一、二辑（Nicene and Post-Nicene Fathers，各14卷）为 19 世纪末 T.&T. Clark 出版的标准英译本，涵盖大部分名单作者。
- 原档来源：CCEL（Christian Classics Ethereal Library）→ https://ccel.org/ccel/schaff/anf01.pdf 等；使徒教父原文（Loeb/Lightfoot）来自 Internet Archive。
- 各分类目录内有 README.md，逐卷列出「作者—著作—文件」对应关系。

## 引用建议

- 学术引用请使用标准版本：ANF/NPNF 按「卷.篇章」引用（如 ANF 1: 188），使徒教父按篇章节（如 1 Clem 59:2）。
- 分类目录为英译本；如需希腊文/拉丁文原文对照，参见各分类 README 中的备注，或提出请求后补充。
- 合计约 455 MB（分类链接不增加占用）。
