# 版权与来源核查记录（修订版）

核查日期：2025-11-12（修订：采纳外部审读意见并逐项复核）
结论：**Lake 1912、Lightfoot–Harmer 1890–1891、GHZ 1906 三个历史版本在美、欧、中三地均为公版，可作翻译底本与校勘对照。Tauber 2019 数字本按 CC BY-SA 4.0 合规使用（署名+保留许可声明），不整体宣称为公版。**

注意：公版是地域性法律结论，以下按美国、欧盟、中国大陆分别计算；
本记录为一般期限计算，不构成全面法律意见。

## 一、三个历史版本

### 1. Lake Loeb《使徒教父》卷一（1912）——权威底本
- 出版：卷一 1912 年 9 月，卷二 1913（London: Heinemann / New York: Macmillan）
- Kirsopp Lake（1872–1946）
- 美国：已出版作品保护期为出版后 95 年 → 1912+95=2007 年底届满，2008 年起公版
- 欧盟（终身+70，指令 2006/116/EC 第 1 条）：1946+70 → 2016-12-31 届满，2017 年起公版
- 中国大陆（著作权法第 23 条，终身+50）：1946+50 → 1996-12-31 届满，1997 年起公版
- 区分三层：古代原始希腊文（无现代版权）／Lake 1912 校订文本（已公版）／Lake 英译（已公版）
- 不可推广为"一切现代校勘本均公版"——现代新校勘、新注释可能仍受保护

### 2. Lightfoot–Harmer《使徒教父》修订本（1890–1891）——校勘对照（含完整异文栏与注释）
- J. B. Lightfoot（1828–1889）撰；J. R. Harmer（1857–1944，澳大利亚传记辞典/维基百科核实）
  编辑完成 1891 年综合本
- 按两人分别计算：
  | 人物 | 卒年 | 欧盟(+70) | 中国(+50) |
  |---|---|---|---|
  | Lightfoot | 1889 | 1960 起公版 | 1940 起公版 |
  | Harmer | 1944 | 2015 起公版 | 1995 起公版 |
- 美国：1890–91 出版，95 年期早已届满 → 公版
- 价值：希腊文校勘 + 完整异文栏 + 引言、注释、历史论证（均可自由使用）

### 3. Gebhardt–Harnack–Zahn《使徒教父著作集》**第五版小型本**（editio quinta minor, 1906）——独立文本对照
- **版次已据本地 PDF 标题页与前言核实：EDITIO QUINTA MINOR, Lipsiae: J.C. Hinrichs, 1906**
  （外部审读引赫尔辛基书目作"第四版"，与原书不符，以原书为准）
- 前言所载版次史：大型本 1875–1877；小型本 1877 初版，1894 重印（二版），
  1900 三版，1902 四版（增圣经索引），1906 五版
- 编者卒年：Gebhardt 1906、Harnack 1930、**Zahn 1933**（美国国会图书馆规范档核实；
  此前误记 1937，已更正）
- 美国：1906+95=2001 年底届满 → 公版
- 欧盟：1933+70 → 2003-12-31 届满，2004 年起公版
- 中国：1933+50 → 1983-12-31 届满，1984 年起公版
- **重要限定**：小型本按前言自述"删去拉丁译文与校勘、释义注释，仅刊希腊文"，
  页下只有圣经引文出处，**无完整异文栏**。完整校勘 apparatus 在大型本（1875–1877）
  及 Lightfoot 本中。故 GHZ 1906 的角色是**独立文本见证**（其正文与 Lake 有实质差异，
  如 1 Clem 1:1 多 ἀδελφοί），不是异文栏来源

## 二、Open Apostolic Fathers 数字本（Tauber & Macdonald, 2019）

- GitHub: jtauber/apostolic-fathers；Zenodo DOI: 10.5281/zenodo.2555673；标注 CC BY-SA 4.0
- 严谨判断（采纳外部审读）：
  1. Lake 1912 原始文本公版；
  2. 纯机械性 OCR 纠错、忠实恢复印刷本的部分，不因劳动投入自动产生新版权
     （美国 Bridgeman v. Corel 原则——注意该案为纽约南区联邦地区法院判例、
     针对艺术摄影复制，非全球通用规则；Project Gutenberg 同立场）；
  3. 但无法仅凭 README 证明全部修改均属机械纠错、无任何独创性编辑贡献；
  4. CC 许可不能把公版内容重新变为受保护内容，也不能对公版部分附加限制（CC 官方 FAQ）。
- **使用策略**：
  - 权威底本 = Lake 1912 印刷本（本地 loeb_lake_v1/ PDF）
  - Tauber 数字本 = 数字化工作稿与校对辅助；差异处回印刷本核实
  - 保留来源信息与 CC BY-SA 4.0 声明，再发布其数字文件时遵守署名+相同方式共享
  - 中文译本以公版 Lake 校勘本为依据，译文版权由译者自主处置

## 三、Archive.org 扫描 PDF

- 原书公版；忠实扫描通常不因扫描行为产生新版权
- 限定：Bridgeman 为美国地区法院判例；欧盟 DSM 指令 (2019/790) 第 14 条仅针对
  **视觉艺术作品**的忠实复制，不能直接推及所有书籍扫描件；CC 2025 文化遗产指引
  属政策立场而非法律
- 扫描文件可能附带独立的元数据、说明或人工文本层；archive.org 访问条款与版权问题分开考虑
- 已确认所下载为 1906 年第五版小型本原书扫描（标题页核实），非后世修订本

## 五、工作原则（公版 ≠ 学术可靠）

1. 希腊文以明确指定的历史印刷版本为依据；
2. 异文记录具体版本与位置，不凭记忆补齐；
3. 直译与意译分开；
4. 译者判断与原文事实分开；
5. 争议处保留不确定性，不强给唯一答案。
