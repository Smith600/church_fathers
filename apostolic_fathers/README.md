## 说明

- 建议以 **Lightfoot 全集**（lightfoot_complete/）作为希腊文校勘底本——它收录最全（含帕皮亚残篇），且有英文对照。
- **Loeb 两卷**为希腊文+英文逐页对照，适合平行阅读。
- OCR 文本（.txt）为扫描识别产物，希腊文多音符处或有错讹，引用请核对 PDF 原页。
- 注意：早期文献的分章编号与和合本/现代译本一致（如 1 Clem 59:2），但不同版本页码各异。
