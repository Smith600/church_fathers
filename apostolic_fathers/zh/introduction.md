# 导言：《致哥林多人前书》（克莱门特一书 / 1 Clement）

## 一、书名、作者与年代

本信原无书名，抄本题记仅作「罗马人致哥林多人的信」（见本书卷末署名）。后世为与同抄本所附的另一篇讲章（"克莱门特二书"）相区别，编号为《克莱门特一书》或《致哥林多人前书》。信以罗马教会全体名义发出，正文不自署作者名；传统归于罗马的克莱门特（Clement of Rome，古代名录中列为罗马教会第三或第四任监督）。

年代约公元 96 年（多米田统治末期或涅尔瓦初年）。内证：1:1「突然降临、接踵而至的灾祸」常解为多米田朝的迫害；44:5「先行离世的长老」暗示使徒世代已过去一代以上；47:1 提及保罗致哥林多书信，称其为「福音的起头」之作。

## 二、写作背景与目的

哥林多教会爆发纷争（στάσις）：少数人起来反对并罢黜了无可指摘地任职的长老（1:1；44:6；47:6；57:1）。罗马教会以母会姿态写信劝和：

- 以谦卑与顺服的榜样劝诫（9–19 章：以诺、挪亚、亚伯拉罕、摩西、约伯、大卫；基督自己为最高榜样）；
- 以嫉恨的恶果警告（4–6 章：该隐以至彼得、保罗与殉道者）；
- 以创造与祭礼的秩序论证教会秩序（20–44 章：军队、身体之喻；使徒设立职分与接续之制，42、44 章）；
- 以爱为纽带呼吁合一（48–50 章）；
- 提出具体出路：煽动者顺服长老（57 章），或自愿退出（54 章）；并差三位使者（克劳狄·以弗布、瓦勒里·彼托、福尔图拿图）携信前往（63:3；65:1）。

全书以一封代求的大祈祷收束（59:2–61:3），是现存新约之外最古老的基督教礼仪祈祷文之一。

## 三、抄本传统与文本问题

**希腊文抄本**
- **A** = Codex Alexandrinus（亚历山大抄本，5 世纪，今藏大英图书馆）：全信附于新约正典之后；**缺页一处：自 57:7 中段（ἀνθ' ὧν γὰρ ἠδίκουν）至 63 章末**，此段倚赖 C 抄本（据 Lightfoot 校勘记核实）；同抄本所附二书止于 12:2。
- **C** = Codex Constantinopolitanus（即 Codex Hierosolymitanus，1056 年书记 Leo 所抄，Bryennios 1875 年发现于君士坦丁堡）：全文完整，并含二书、巴拿巴书、十二使徒遗训等。

**古译本**
- 古拉丁译本（L）：抄本 11 世纪，但译本极古，或为 2 世纪末–3 世纪初罗马所出，曾为拉克坦修使用；Morin 1894 年刊行。
- 叙利亚译本（S）：剑桥大学图书馆 MS add. 1700，1169 年抄。
- 科普特译本（Akhmim 方言）：两残本（柏林 4 世纪纸草；斯特拉斯堡 7 世纪本）。

**其他见证**：亚历山大的克莱门特《杂记》多次引本信并视同圣经；本信在 A 及科普特本中紧接正典，反映早期埃及教会曾将其视为新约一部分。

**重要异文与文本问题**（详见各章注）：
- 1:1 περιπτώσεις（A）／περιστάσεις（C 及古拉丁）；GHZ 1906 另有 ἀδελφοί。
- 2:1 τοῦ Χριστοῦ（底本、GHZ）／τοῦ θεοῦ（A，据 Lake 校勘栏）。
- 45:1 有无否定词之读法分歧。
- 57:7–63:4 A 抄本缺页（见上）。
- 59:3 开头残缺。

## 四、结构与神学焦点

| 段落 | 内容 |
|---|---|
| 卷首–3 | 问安；哥林多昔日之美与今日之乱 |
| 4–6 | 嫉恨目录：旧约例子、彼得与保罗、殉道妇人 |
| 7–8 | 悔改的呼召（辑引结、赛） |
| 9–12 | 信与好客的榜样：以诺、挪亚、亚伯拉罕、罗得、喇合 |
| 13–19 | 谦卑：基督为榜样（引赛 53、诗 51） |
| 20–38 | 创造的秩序与教会的秩序（军、身之喻；32:4 因信称义） |
| 39–47 | 祭礼秩序、职分与接续（42、44 章）；斥分裂 |
| 48–50 | 爱的纽带（爱颂） |
| 51–58 | 顺服的劝勉与智慧的警告 |
| 59–61 | 代求大祈祷；为在位者代求 |
| 62–65 | 结语、差使、祝福；抄本题记 |

神学焦点：32:4 因信称义（全书最保罗化之句）；36 章大祭司基督论（引来 1 章语链）；42、44 章职分秩序与使徒接续；49 章爱之纽带；59:2–4 与 64 章的祈祷文。
